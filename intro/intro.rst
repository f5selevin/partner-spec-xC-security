Introduction and prerequisites
##############################

This workshop introduces core F5 Distributed Cloud Services concepts through hands-on exercises using the Arcadia Crypto application. You will work in a dedicated UDF environment and an F5 Distributed Cloud tenant.

Complete every section below before starting the application delivery exercises. These mandatory steps explain how to create or verify your F5 account, join the UDF deployment, reset your tenant password, and sign in to the F5 Distributed Cloud Console. Without this preparation, you may be unable to access the workshop resources or complete the exercises. Contact your workshop host if you do not receive the required invitations.

F5 Distributed Cloud HTTP Load Balancer Basics
==============================================

Publish the public Arcadia Crypto application with origin pools and an HTTP Load Balancer, verify round-robin traffic distribution, and apply foundational application security controls. You will configure and test WAF, IP Intelligence, and Malicious User Detection, then review security events and blocked users.

Multi-Cloud Networking
======================

Extend Arcadia Crypto across AWS and the private on-premises Kubernetes environment. You will route application services to the appropriate locations and establish connectivity between environments so cloud-hosted services can securely communicate with services that remain on premises.
