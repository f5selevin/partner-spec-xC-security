Review the Requests dashboard
#############################

Use the Requests dashboard to review traffic generated during the WAF, API Security, and Bot Defense exercises.

1. In **Web App & API Protection**, go to **Overview** > **Security**.
2. In the **Delivery Resources** tile, select the ``arcadia-finance`` HTTP load balancer.
3. Open the **Requests** tab.
4. Set the time range to **Last 24 hours**, select **Apply**, and refresh the dashboard.
5. Review representative allowed and denied requests. Expand individual requests and compare the path, method, response code, source, request ID, latency, and enforcement metadata.
6. Filter for traffic generated by the earlier exercises, including:

   * WAF test requests to ``/accounts``.
   * API Protection and rate-limit tests.
   * Browser and automated Bot Defense tests to ``/payments``.

7. Confirm that the displayed results correspond to the tests you performed. Adjust the time range and filters if an expected request is not shown.
