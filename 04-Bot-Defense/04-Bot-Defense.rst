Protect the Arcadia Finance Payments API from Automated Traffic
################################################################

Automated traffic protection
****************************

Application and API endpoints receive traffic from wide variety of sources. 
Traditional access controls and attack signatures do not determine whether 
a valid request was generated by a human or an automated client.

F5 Distributed Cloud (XC) Bot Defense analyzes client behavior and request
signals to classify automated traffic. Bot Defense Standard applies this
capability on the HTTP load balancer and enforces a configured mitigation action
on protected application endpoints.

Endpoint mitigation
*******************

For the Arcadia Finance payments API, the policy protects ``POST /api/payments`` 
and returns ``403 Forbidden`` when the **Block** mitigation action is applied.

Browser traffic is evaluated independently from direct scripted requests. This
allows the application workflow to continue while automated clients attempting
to call the same endpoint are blocked.
